# 英语冒险岛链 (English Adventure Islands)

## Problem Statement

How Might We 让一个 8-9 岁的三年级孩子在暑假里，通过手机用自己设计的"闯关 → 金币 → 装扮/盲盒"机制和一部连续冒险故事，主动地、开心地每天花 10-15 分钟，把人教版英语三年级上册的 6 个单元、约 90 个核心词汇"混个脸熟"、建立对英语的正反馈？

## Recommended Direction

产品 = 连续冒险故事壳 + 孩子自创的闯关经济循环 + 强悬念节奏控制。

- **故事壳**：6 个教材单元 = 6 个冒险世界（章节），孩子是主角，每章通关推进剧情，章末悬念预告制造"追更"。
- **核心循环（孩子本人定义）**：闯关（英语即通关）→ 得金币 → 金币买装扮（确定性）或抽盲盒（随机惊喜）→ 主角形象实时变化 → 更想闯关。
- **学习机制**：单词镶嵌在剧情与关卡里。**四步学习流水线（学习递进）**：先听发音 → 跟读建立语感 → 才能进入听音选词 / 看图选词。零基础必须先输入再输出，最后才检验。
- **节奏控制**：强悬念预告 + 每日软限制（延迟满足），每天只解锁一章（约 10-15 分钟），保习惯养成。
- **技术**：PWA 纯前端 + Edge TTS（实测国内直连可用）+ Cloudflare Pages + IndexedDB 本地进度，无后端。
- **语音评测分期**：一期"原音对比自评"（录音回放，孩子耳朵当裁判），二期再引入 AI 评测。

## Key Assumptions to Validate

- [ ] 兴趣假设：孩子会主动要求"今天要闯关"（连续 7 天主动使用）→ 单章可玩闭环后立即给孩子试玩
- [ ] 金币经济能驱动持续回访且不腻（盲盒随机惊喜有效，装扮追求持续）
- [ ] Edge TTS 在孩子手机上音质、响应、国内网络可达性均可用
- [ ] "单词镶嵌在剧情里"对"混个脸熟"目标的有效性 ≥ 传统背诵
- [ ] 9 岁孩子能理解并接受盲盒保底逻辑（防挫败设计）

## MVP Scope

- 剧情演出引擎（逐行文本 + Edge TTS 朗读 + 场景图，文字冒险式播放器）
- 6 章完整剧本（JSON 内容数据，与代码分离，单词镶嵌关卡中）
- 四步学习流水线关卡：听（Learn）→ 跟读（Repeat）→ 听音选词（Listen & Choose）→ 看图/看词选词（Look & Choose）
- 金币经济：产出规则 + 装扮商店（确定性购买）+ 盲盒（含保底）
- 冒险地图 + 章末悬念预告 + **每日软限制（延迟满足）** + 本地存档（IndexedDB）
- PWA：可安装到主屏、离线可用

## Not Doing (and Why)

- **账号 / 云同步 / 多设备** —— 孩子独立使用单设备，IndexedDB 本地存储足够，省去后端。
- **家长看板** —— 孩子独立使用，家长用"问孩子 + 抽查"替代。
- **真实 AI 语音评测（二期）** —— STT 引入依赖与国内网络不确定性，一期用自评先验证兴趣。
- **社交 / 排行榜** —— 9 岁隐私 + 独立使用，无需求。
- **真实货币 / 内购** —— 绝不做；盲盒纯游戏内金币驱动，守住多巴胺机制边界。
- **大制作动画 / 音效** —— CSS 动画 + emoji/SVG 场景图足够撑起体验。
- **教材图片素材** —— 版权规避，全部用原创/通用图形。

## Open Questions

- 金币经济数值最终调优（MVP 用合理默认值，试玩后调整）
- 盲盒概率与保底的具体数值体验（试玩后观察孩子是否受挫）

## Confirmed Decisions (已确认)

- **故事基调**：魔法冒险（主角捡到会说话的魔法英语书，词语被咒语打散，跟读"念咒语"把词救回来）
- **每日软限制**：延迟满足，必做——当日章节完成后"今日冒险已完成，明天见"，不提供一键解锁
- **金币数值**：MVP 用合理默认值，试玩后调整
