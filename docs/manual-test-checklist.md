# 手动验收清单（真机测试）

目标设备：**Android Chrome**（孩子手机），有条件时另测 iOS Safari。
前提：应用已部署（`https://你的域名/`）或本地 `npx serve src` + 手机连同一局域网访问 `http://电脑IP:4173`。

## A. 安装与打开

- [ ] 手机浏览器打开应用，可看到"冒险地图"页
- [ ] 可"添加到主屏幕"（Chrome 菜单 → 添加到主屏幕），图标显示
- [ ] 从主屏图标打开，无浏览器地址栏（standalone 模式）
- [ ] 飞行模式（断网）下再次打开，应用仍可启动并显示已缓存内容

## B. 冒险地图与每日软限制

- [ ] 地图显示 6 座岛，第 1 章可挑战，第 2-6 章锁定 🔒
- [ ] 点锁定岛屿无反应（或提示先完成前面的）
- [ ] 完成第 1 章后，第 2 章变为"可挑战 · 明天见"
- [ ] 当天再点未完成章节，显示"今日冒险已完成，明天见"（延迟满足生效）
- [ ] 已完成章节可随时重玩（复习）

## C. 剧情演出

- [ ] 点开章节先播放开场剧情，逐行显示说话人（emoji+名字）和台词
- [ ] 中文台词能朗读（女声），英文台词能朗读
- [ ] 点"下一句"逐行推进，最后一句按钮变"出发闯关 🚀"
- [ ] 章末"悬念预告"文案能勾起好奇心

## D. 闯关（四步学习流水线）——核心

- [ ] **新词必须先"听"**：进入学习卡片自动朗读，可反复点"听一听"
- [ ] 学习卡片显示 单词+音标+中文+图形
- [ ] **跟读自评**：能录音（🎤），录完可"听我的"回放，与"听原音"对比；点"我读得像"通过
- [ ] 无麦克风权限时，显示友好提示而非报错
- [ ] **听音选词**：听发音从 4 个候选中选词，答对"🎉 太棒了"，答错鼓励"再想想哦"
- [ ] **看图选词**：看图形选英文单词
- [ ] 已学过的词（再次进入章节）直接跳过"听/跟读"，直接进检验题

## E. 金币与经济

- [ ] 通关结算页显示"💎 集齐第 N 片宝石 + 🪙 金币数"
- [ ] 金币到账，顶部余额实时更新
- [ ] 刷新/重启后金币、进度、装扮、盲盒计数全部保留

## F. 商店与盲盒

- [ ] 商店列出可购买装扮，金币够可买，不够提示"金币不够"
- [ ] 盲盒可抽，显示抽取结果（普通/稀有✨/传说🌟）
- [ ] 抽满保底次数必出传说（可连续抽验证）

## G. 装扮

- [ ] 装扮页显示主角形象（基础形象+已装备装扮叠加）
- [ ] 点击已拥有的装扮可穿戴，预览立即变化
- [ ] 重新进入后装备保留

## H. 声音与语音（真机重点）

- [ ] 中文、英文朗读音质清晰、无卡顿
- [ ] 断网/网络差时朗读失败有提示，应用不卡死（可继续闯关）
- [ ] （可选）孩子在安静环境跟读，自评录音回放清晰

## 已知限制（MVP）

- 语音评测为"录音回放自评"，AI 自动评分在二期
- 进度仅存本设备（换手机/清缓存会丢）
- 无账号、无排行榜、无家长看板
